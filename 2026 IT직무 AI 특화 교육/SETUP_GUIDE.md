> 💡 **왜 Q28~Q31은 12월에만?**
> - Q28(Pre): 6개월 후 회상해야 정확. 7~11월에 매달 하면 비교 의미가 약해짐
> - Q29~Q31(영향 평가): 최종 종합 시점에만 측정
> - Apps Script는 이 문항이 없으면 자동으로 null 처리하므로 다른 월에 추가해도 문제 없음

### 1-2. Apps Script 셋업

1. 시트 열기 → **확장 프로그램 → Apps Script**
2. 기존 코드 전부 지우고 `Code.gs` 내용 붙여넣기 → 저장
3. (선택) `runDiagnose` 실행 → 모든 시트의 헤더/신규 문항 인덱스 확인
4. **배포 → 새 배포 → 웹 앱 → "모든 사용자"** → URL 복사

### 1-3. HTML에 URL 붙여넣기

`index.html`의 `APPS_SCRIPT_URL = ""` ← URL 붙여넣기 → 새로고침

## 📊 2단계: 효용 보고서 패널 안내 (7개)

대시보드 하단, 월별 탭 아래의 **"✨ 효용 보고서"** 섹션에 다음 7개 패널이 표시됩니다.

### 🛠️ 업무 적용률 KPI
- Q23 응답 중 1개 이상 선택한 비율
- **목표**: 80% 이상이면 교육이 실제 업무에 활용되고 있음

### ⏱️ 주당 절약 시간 KPI
- Q24 응답의 평균 (구간값 → 시간)
- **예**: 18명 × 평균 5h = **90h/주 절감**

### 📈 자기 효능감 변화 KPI
- Q27 (현재) vs Q28 (6월 회상) 차이
- 12월에만 표시 (Pre/Post 비교)

### ⭐ 교육 NPS KPI
- Q30 평균 + 추천/중립/비추천 분포
- NPS 스코어 = (추천% - 비추천%)

### 💰 ROI 계산기
- 인당 시급 / 학습비 / 인원 입력 → 자동 계산
- **월 절감액 / 연 절감액 / ROI% / Payback 기간** 자동 표시
- 기본값: 시급 25,000원 / 학습비 500,000원 / 20명

### 🛠️ 업무 적용 사례 분포
- Q23 응답의 항목별 카운트 + 시각화 바
- 어느 영역에서 가장 많이 활용되는지

### ⏱️ 월별 절약 시간 추이
- 7~12월 평균 주당 절약 시간 라인 차트
- 학습 진행에 따라 절약 시간이 어떻게 증가하는지

### 🌟 Best Practice 사례집
- Q17(매달) + Q28(12월) 의견 모음
- 최신 6건 자동 표시

### 🏆 Knowledge Sharing 리더보드
- Q26(동료 공유) 활동 점수 TOP 8
- 골드/실버/브론즈 뱃지

### 📊 자기 효능감 Pre/Post 차트
- 12월 Q27 vs Q28 막대 차트

### 📋 후속 교육 수요
- 12월 Q31 의견 모음
- 차기 교육 계획 수립에 활용

## 🛠️ 4단계: 트러블슈팅

### 효용 보고서가 비어있어요
- 7~12월 시트에 데이터가 들어와야 표시됨
- 신규 문항(Q23~Q31) 헤더 prefix 확인 (Apps Script는 "Q23.", "Q24." 등 prefix 매칭)
- `runDiagnose` 실행으로 헤더 인덱스 확인

### ROI 계산이 이상해요
- 시급/학습비/인원 값을 대시보드에서 직접 조정 가능
- 응답자 수가 적으면 ROI가 낮게 나옴 → 정상

### Best Practice가 안 보여요
- Q17 또는 Q28에 의미있는 응답이 있어야 표시
- "없음", "해당사항 없음" 같은 응답은 자동 필터링됨

### 캐시 문제 (구버전 데이터가 보여요)
- 하드 새로고침: `Ctrl + Shift + R` (Mac: `Cmd + Shift + R`)
- 콘솔에서 `localStorage.clear()` 실행
- 캐시 키: `ai_training_cache_v3` (v3로 변경됨, 구버전 캐시 자동 무효)
